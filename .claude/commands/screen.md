# Screen

Call `screening_get_maverick_stocks` and `screening_get_maverick_bear_stocks` in parallel.

Show two compact lists:

**Accumulate** (bullish screen hits, ranked by score)
**Bear/Avoid** (bearish screen hits)

One line per ticker: `TICKER  score  key signal`

If $argument is provided, filter to only show that ticker.
No disclaimers.
