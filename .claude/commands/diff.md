# Conviction Diff

Call `conviction_diff` from maverick-mcp.

If $argument is a number, use it as days_back. Default is 7.

Show:
**New entrants** — tickers that appeared for the first time
**Exits** — dropped off the ledger
**Movers** — biggest conviction score changes (show delta with arrow ↑↓)
**Tier changes** — anything that was high-conviction and went off-screen

Keep it tight. Flag anything that affects a held position with ★.
